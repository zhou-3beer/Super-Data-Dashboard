Redmine の進捗率を見やすくするダッシュボード

Redmine の issues API から取得した JSON を貼り付けると、全体進捗・完了数・遅れ気味のチケットを見やすく確認できます。

使い方

  1. Redmine の issues API レスポンス JSON をコピー
  2. 下の入力欄へ貼り付け
  3. 「進捗を更新」を押す

Redmine データ入力

全体進捗 0%
完了チケット 0 0 件中
進行中 0 25%〜99%
要確認 0 50% 未満
